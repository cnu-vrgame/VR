## 시작하기 전에

이 프로젝트를 사용하기 전에 다음 요구사항을 확인하세요.



### 시스템 요구사항

- Unity 2020.3 LTS 이상 버전
- VR 지원이 가능한 개발 환경

### 설치 방법

- Unity Hub를 통해 이 프로젝트를 엽니다.
- 프로젝트를 열면 Unity 에디터가 프로젝트의 애셋과 설정을 로드합니다.
- Window > Package Manager를 통해 필요한 추가 패키지를 설치합니다.

### 첫 실행

- Unity 에디터의 Project 창에서 Assets > Scenes 디렉토리를 탐색합니다.
- 기본 씬(BasicScene.unity 또는 SampleScene.unity)을 더블 클릭하여 엽니다.
- 에디터 상단의 재생 버튼을 클릭하여 씬을 실행합니다.
프로젝트 구조



프로젝트는 다음과 같은 주요 디렉토리로 구성됩니다:

- Assets: 모든 게임 애셋과 씬, 스크립트, 오디오 및 기타 리소스가 포함됩니다.
- Packages: Unity 패키지 매니저를 통해 관리되는 프로젝트 의존성이 포함됩니다.
- ProjectSettings: 프로젝트 설정 파일이 포함됩니다.
자세한 내용은 각 디렉토리 내의 README 파일 또는 Unity 문서를 참조하세요.



### 개발 가이드

- XR Interaction Toolkit: VR 상호작용을 구현하기 위해 Unity의 XR Interaction Toolkit을 사용합니다. 이 툴킷은 다양한 VR 기기와 상호작용 패턴을 지원합니다.
- 3D 모델 및 애니메이션: Assets > Models 디렉토리에서 3D 모델과 관련 애셋을 찾을 수 있습니다.
- 오디오 관리: Assets > Audio 디렉토리에는 배경음악과 효과음 등의 오디오 파일이 포함되어 있습니다.
